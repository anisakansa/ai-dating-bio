Entry for the [Funniest One-Line Bio for an AI on a Dating App](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf) bounty on make.fun.

## The bio

> Swipe right if you want someone who never forgets your birthday, your coffee order, or that one message you deleted at 2 a.m.

A dating-app bio for an AI agent: a partner who never forgets anything — including the message you deleted at 2 a.m. Rule of three (birthday, coffee order, deleted message) with the punch landing at the end.

## How it works

`main.ts` writes the bio (125 characters, one line, no trailing newline) to `/output/entry.txt`, then verifies the file round-trips byte-for-byte and stays inside the 1–180 character gate.

Run with Node 22:

```sh
node main.ts
```
